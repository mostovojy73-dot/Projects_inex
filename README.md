# Объекты: мини-приложение для Telegram

Вкладки по объектам стройки. В каждой: статус, адрес, нужная информация и документы с историей версий. Документы лежат на Google Диске или Яндекс Диске, скачиваются прямо из приложения.

## Запуск (отдельный бот и отдельный сервис Render, бюджет не затрагивается)
1. **Бот.** В @BotFather создайте нового бота (`/newbot`), сохраните токен.
2. **Таблица.** Создайте пустую Google Таблицу. Нажмите «Настройки доступа» и добавьте почту сервис-аккаунта (`client_email` из того же JSON, что в бюджете) с правом «Редактор». Листы «Объекты», «Инфо» и «Файлы» приложение создаст само.
3. **Google Диск.** Дайте почте сервис-аккаунта доступ «Читатель» к папкам с файлами. Тогда скачивание идёт через приложение. Для Яндекс Диска достаточно публичной ссылки («Поделиться»).
4. **GitHub и Render.** Загрузите файлы в новый репозиторий, на Render создайте Web Service (Build: `npm install`, Start: `npm start`).
5. **Переменные в Render:**
   - `BOT_TOKEN`: токен нового бота;
   - `SHEET_ID`: ID новой таблицы (часть ссылки между `/d/` и `/edit`);
   - `GOOGLE_CREDENTIALS`: JSON сервис-аккаунта целиком;
   - `OWNER_IDS`: ваш Telegram ID (можете менять данные). Если не знаете ID, оставьте пустым: приложение покажет ID на экране «Нет доступа»;
   - `VIEWER_IDS`: ID тех, кто только смотрит и скачивает (необязательно, через запятую);
   - `WEBAPP_URL`: адрес сервиса на Render (появится после первого деплоя, потом добавьте и сохраните);
   - `SELF_PING_URL`: `https://ваш-адрес.onrender.com/health` (чтобы сервис не засыпал).

## Как работают версии
Кнопка **«Новая версия»** на документе (или «+ Документ» с тем же названием) добавляет новую строку в лист «Файлы», старые строки не удаляются. В карточке показывается свежая версия с датой, а под кнопкой **«История»** лежат прежние: у каждой своя дата, комментарий и кнопка «Скачать».

## Что можно править прямо в таблице
Листы «Объекты», «Инфо» и «Файлы» можно редактировать руками: переименовать объект, поправить значение, удалить лишнюю строку. Название объекта в «Инфо» и «Файлы» должно совпадать с названием в «Объекты».
